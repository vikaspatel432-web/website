# Tool / software logos

Drop the official logo files here to light up the "tools we work with" strip on
the home page. Until a file exists, the strip falls back to the tool's name as
text (no broken images), so it's safe to add them one at a time.

Use the **official** brand assets (download from each vendor's brand/press page).
**SVG with a transparent background** is best; transparent PNG also works.
The strip renders logos in neutral grey and reveals full colour on hover, so
single-colour or full-colour logos both look fine.
